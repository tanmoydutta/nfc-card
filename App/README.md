# iPhone app

See [NFC Sensor Lite](NFCSensorLite/) for the standalone SwiftUI app that reads the latest SHT40 temperature and humidity through NTAG 5, without reading history.

Open `NFCSensorLite/NFCSensorLite.xcodeproj` in Xcode, choose your signing team and a unique bundle identifier if needed, and run on an NFC-capable iPhone with iOS 17 or later. See the project README for configuration details.
